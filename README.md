# Duel Forge 0.25（revision 82）

使用2026-10-12 13:38上传的英雄配置与设置作为默认值，补入本次新增内容，普通包仅含26位常规英雄。所有英雄普攻前摇为普攻间隔的0.15倍。

Windows包使用本次上传的完整启动器。解压整个文件夹后运行DuelForge.exe，保持DuelForge.pck位于同一目录。

设置→对局规则顶部：场上有战神时，可为双方即时设置决斗攻击力；有狗头时，可单独设置汲魂痛击层数。联机由房主设置。

袋鼠改用红橙色，E有双方可见的蓝色矩形范围与免疫控制条，R双方有挑战条和拳套标记。W固定突进1000码，沿冲锋方向到达敌人另一侧，150ms绕后加150ms后摇。Q附伤按当前总攻击速度计算，独立于普攻暴击。

剑姬Q刺击搜索范围350码；W双方可见反击范围与免疫伤害条，招架行动限制会弹出“招架！”。破绽使用地图固定方位的金色弧线及指向标记；治疗阵随状态同步，恢复状态立即移除。

源码使用Godot 4.4.1标准版打开project.godot。默认配置在data/catalog.json及data/default_settings.cfg。

每轮破绽：北/东随机→另一处→南/西随机→另一处，四位置不重复，地图方位固定。剑姬Q速度1800。修复平面标记的背面剔除与遮挡，增加外围金色方位标记；剑姬大招不显示挑战进度条，袋鼠挑战保持显示。

本次格挡修正详见 docs/v025-r78-CHANGELOG.txt。

控制招架与投掷交互更新见 docs/v025-r79-CHANGELOG.txt。
